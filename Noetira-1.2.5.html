Noetira 1.2.5（Build 55）

修复

  • 修复 Hermes / 本地 Agent 连接偶发「缺少有效令牌」：Agent 令牌改为跨启动持久化，App 重启后不再因令牌轮换而失配。
  • 今日计划新增完成度展示：顶部与「计划完成」卡片显示完成百分比与进度条，单个任务行显示部分完成进度（未开始 / 百分数 / 完成）。
  • 今日计划任务可设置开始时间，到点通过 macOS 原生通知提醒（默认提示音）；完成任务、删除任务或存入待安排时会自动取消提醒。
  • Hermes 接口同步支持完成度：/api/learning/today 每项任务新增 completion、focusedSeconds，统计新增 planPercent。
  • 移除语言设置中的 English 选项，仅保留「跟随系统」与「简体中文」，默认简体中文，避免切换英文后部分界面仍显示中文。
  • 专注页时长按钮（25/40/50/60/90 分钟）改为仅边框 + 框内浅色底色，并移除按钮外围多余底色。

岗位信息、AI 核验、公告线索和本地初筛均为辅助信息，最终以招录机关官方公告和资格审查为准。
